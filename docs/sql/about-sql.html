Цей розділ присвячений мові SQL — мові запитів до баз даних.

SQL використовується для отримання, фільтрації та аналізу даних, які зберігаються у таблицях.

Що таке SQL простими словами

SQL (Structured Query Language) — це мова, за допомогою якої ми ставимо запитання базі даних.

  • Покажи всіх клієнтів з Німеччини
  • Знайди найдорожчі продукти
  • Порахуй, скільки замовлень у базі

Дані в базі зберігаються у вигляді таблиць, схожих на Excel:

  • рядки — записи (дані)
  • стовпці — поля (властивості)

Де ми будемо працювати

Типи SQL-завдань

1. Завдання на вибірку даних (SELECT)

У цих завданнях ми навчимось:

  • отримувати дані з таблиць
  • використовувати SELECT, WHERE, ORDER BY
  • фільтрувати та сортувати результати

👉 Перейти до завдань на вибірку (SELECT)

2. Інші SQL-завдання

Зʼявляться пізніше:

  • робота з кількома таблицями (JOIN)
  • групування даних (GROUP BY)
