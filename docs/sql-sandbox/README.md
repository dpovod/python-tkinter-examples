# SQL-пісочниця

Сторінка сайту для практичної роботи з SQL (10 клас): `/sql-sandbox/`. SQLite працює прямо в браузері через [sql.js](https://github.com/sql-js/sql.js) 1.10.3 (WebAssembly), сервер не потрібен. sql.js лежить у `vendor/`, тому пісочниця не залежить від CDN.

Інтерфейс — «вікно клієнта БД» (унизу лівої панелі є кнопка «Готові таблиці»): панель інструментів, ліва панель з деревом таблиць, редактор з підсвіткою SQL, нижня панель з вкладками (результати, «Повідомлення», «Історія») і рядок стану. На екрані вужчому за 900 px усе йде в одну колонку, таблиці стають «чипами», меню таблиці відкривається знизу.

## Що зберігається у браузері (`localStorage`)

| Ключ | Вміст |
|---|---|
| `sql-sandbox-db` | уся база (`db.export()` у base64), оновлюється після кожної зміни; відновлюється при відкритті |
| `sql-sandbox-history` | історія запитів (до 200) |
| `sql-sandbox-editor` | текст у редакторі |
| `sql-sandbox-params` | останні введені значення параметрів |
| `sql-sandbox-ui` | висота нижньої панелі |

«Очистити базу» стирає й збережену копію. Якщо сховище недоступне чи переповнене, пісочниця працює далі, а в рядку стану з'являється «⚠ базу не вдалося зберегти в браузері».

## Файли

- `index.html` — сторінка (макет `lesson`, запис `sql-sandbox` у `_data/lessons.yml`);
- `style.css` — стилі на токенах `assets/css/site.css`, усі правила під `.sbx`;
- `app.js` — уся логіка;
- `vendor/sql-wasm.js`, `vendor/sql-wasm.wasm` — sql.js 1.10.3.

## Можливості

- **Виконання.** Кнопка «Виконати» (над редактором; на телефоні — під ним, на всю ширину) і Ctrl/Cmd+Enter виконують усе, що є в редакторі (виділення й «поточний запит» не використовуються). Межі запитів визначаються за `;` з урахуванням лапок, коментарів і тіла `CREATE TRIGGER`.
- **Меню таблиці** (єдиний спосіб швидких дій; кнопка ⋯, правий клік, Shift+F10 або клавіша меню, довге натискання на телефоні): «Усі записи», «Перші 10», «Кількість», блок «Шаблони» (лише вставка в редактор; пункти зверху мають позначку ▶ і виконуються, шаблони — ✎) (`SELECT`, `SELECT … WHERE`, `INSERT`, `UPDATE … WHERE`, `DELETE … WHERE` з готовими прикладами значень, лише вставка в редактор), «Видалити таблицю…». Запити з меню виконуються тією самою функцією, позначаються «з меню» (готові таблиці — «готова таблиця») в результаті й історії, не змінюють редактор і не потрапляють у `.txt`.
- **Параметри.** `:назва` у запиті (можна кирилицею) — перед виконанням з'являється вікно зі значеннями; вони передаються через `stmt.bind()`, а не підстановкою в текст.
- **Безпека даних.** `UPDATE`/`DELETE` без `WHERE` — запитує підтвердження з кількістю записів; «Очистити історію» — з підтвердженням.
- **Меню бази** (⋯ біля заголовка «База» або правий клік по ньому): «Тестова таблиця» («Створити й заповнити» або «Показати SQL у редакторі»), «Показати схему» і «Очистити базу».
- **Підтвердження** (видалення таблиці, очищення бази чи історії, `UPDATE`/`DELETE` без `WHERE`, «почати спочатку») — маленьке модальне вікно, решта сторінки розмита. Для небезпечних дій фокус стоїть на «Скасувати».
- **Зовнішні ключі.** `PRAGMA foreign_keys = ON` виставляється при відкритті бази, після очищення і після кожного збереження (sql.js скидає його в `export()`). Схема відкривається у великому модальному вікні: картки таблиць і лінії `FK → PK` за `PRAGMA foreign_key_list`; картки можна перетягувати, вікно гортається, масштаб — кнопками «− / + / 100%» або Ctrl/Cmd + коліщатко (ущипування на тачпаді).
- **Підказки до помилок:** немає поля/таблиці, забуті лапки (кириличне слово), синтаксис, `DESCRIBE`/`SHOW`/`USE` (їх немає в SQLite), `FOREIGN KEY constraint failed`.
- **CSV** — роздільник `;` (щоб відкривалось в українському Excel), кодування UTF-8 з BOM.

## Готові таблиці

Кнопка «Готові таблиці» внизу лівої панелі відкриває вікно з картками наборів. Набори лежать у `ready-tables.js` (підключається перед `app.js`) як масив `window.SQL_READY_TABLES`:

```js
{ id: 'movies', title: 'Фільми та серіали', sql: 'CREATE TABLE movies (...); INSERT INTO movies VALUES ...;' }
```

Щоб додати набір, допишіть ще один елемент у масив: `id` (унікальний, латиницею), `title` (назва в картці), `sql` (`CREATE TABLE` + `INSERT`). Назви таблиць беруться з усіх `CREATE TABLE` у `sql`; схема й кількість записів рахуються у тимчасовій базі при першому відкритті вікна. Код змінювати не треба. «Створити заново» видаляє таблиці набору у зворотному порядку створення, тому в `sql` спочатку створюйте батьківські таблиці, а потім залежні.

## Підсвітка синтаксису

Прозорий `textarea` лежить поверх `<pre aria-hidden>`; обидва шари мають однакові шрифт, відступи й `pre-wrap`, прокрутка синхронізується. Номери рядків — CSS-лічильник усередині шару `pre`, тому вони збігаються з перенесеними рядками. Без JS лишається звичайний `textarea`.
