# SQL-пісочниця

Сторінка сайту для практичної роботи з SQL (10 клас): `/sql-sandbox/`. SQLite працює прямо в браузері через [sql.js](https://github.com/sql-js/sql.js) 1.10.3 (WebAssembly), сервер не потрібен. sql.js лежить у `vendor/`, тому пісочниця не залежить від CDN.

База створюється порожньою при відкритті сторінки і зникає після перезавантаження. Історія запитів зберігається в `localStorage` браузера.

## Файли

- `index.html` — сторінка (макет `lesson`, запис `sql-sandbox` у `_data/lessons.yml`);
- `style.css` — стилі на токенах `assets/css/site.css`, усі правила під `.sbx`;
- `app.js` — уся логіка;
- `vendor/sql-wasm.js`, `vendor/sql-wasm.wasm` — sql.js 1.10.3.

## Як змінити навчальну таблицю

У `app.js` на початку є константа `TEMPLATE_SQL` з коментарем над нею. Замініть SQL усередині на потрібний (`CREATE TABLE` + `INSERT`). Кнопка «Вставити запит для створення тестової таблиці» лише вставляє цей текст у поле, виконує його учень сам. Більше нічого міняти не треба.

## Локальний запуск

Через `file://` WebAssembly не завантажиться. Запускайте сайт через Jekyll: `scripts/jekyll.sh serve`, сторінка буде за адресою <http://127.0.0.1:4000/python-tkinter-examples/sql-sandbox/>.
